# Obsidian Vault

Open this folder as an [Obsidian](https://obsidian.md) vault. It is organized
into five folders plus a set of note templates.

## Folders

| Folder | Purpose |
| --- | --- |
| `Theory/` | Concept notes, definitions, governing equations |
| `Derivations/` | Step-by-step derivations and proofs |
| `Diagrams/` | Mermaid / Excalidraw / draw.io / TikZ sketches and exports |
| `Code/` | Code snippets, scripts, and runnable examples |
| `Labs/` | Lab logs, measured data, and experiment write-ups |

## Templates

Note templates live in `Templates/`. Point the **Templater** (or core
Templates) plugin at that folder, then insert a template when creating a note.

## Plugins

Community plugins must be installed manually; see [`PLUGINS.md`](PLUGINS.md).
