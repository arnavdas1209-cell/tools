# Obsidian Plugins (install manually)

Obsidian community plugins are not bundled with this repo. Install each from
**Settings -> Community plugins -> Browse**, then enable it.

| Plugin | Why |
| --- | --- |
| **Excalidraw** | Hand-drawn diagrams and sketches embedded in notes |
| **Mermaid Tools** | Helpers for authoring Mermaid flowcharts/diagrams |
| **Advanced Tables** | Ergonomic Markdown table editing and formatting |
| **Dataview** | Query notes/metadata as tables and lists |
| **Templater** | Powerful templating beyond the core Templates plugin |
| **Zotero Integration** | Pull citations and references from Zotero into notes |
| **LaTeX Suite** | Fast LaTeX math input with snippets and auto-fractions |

After installing Templater, set its template folder to `Templates/`.
